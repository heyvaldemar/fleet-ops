# Controls, and the checks that prove them

This page maps four frameworks onto the public repositories of this account: SLSA v1.0 (the Build track), NIST SP 800-218 (the Secure Software Development Framework, version 1.1), the OWASP Top 10 for LLM Applications 2025, and Article 12 of the EU AI Act. Each row names the check that proves the control, links the file at the commit a passing run tested, and links that run. A row with no such check is a gap and says so, with what is missing.

Read on 2026-10-27. Every run below was read back from GitHub's API that day as completed, successful, and on the commit its file links are pinned to, so the line a link opens is the line that ran. One exception is marked where it occurs: the release verify job (SLSA row 5) ran from a temporary branch, with a release's tag written into the same steps. Links to documents rather than checks (a decision record, a threat model) point at the commit that last changed them.

**What counts as proof.** A test, a planted violation (a change a check must refuse, run in CI so the check is seen to fail), or a CI step whose green run shows the behaviour. A document is not proof: where only a document exists, the row is a gap and links the document.

**What this does not claim.** No framework is "met" here. SLSA splits its Build levels between the producer and the build platform, and the rows only the platform can prove are gaps in this account. Article 12 binds providers of high-risk AI systems; nothing in these repositories is one by itself, and its rows show which logging a provider building on the flagship could point to.

**Status.** *Shown*: a check proves it and a green run shows the check. *Partly shown*: part of the requirement is proven; the cell says which part is not. *Gap*: nothing proves it. *Not applicable*: the requirement's own scope excludes everything here.

**Planted violations.** Across the five Kubernetes repositories the catalog counts 163 static plants (rows of a `plants.tsv` that a static check must refuse), 42 admission plants (manifests a running cluster must refuse) and 8 admitted controls (manifests it must admit, so that a refusal means something): [fleet.json, `planted_violations`, measured 2026-10-27 12:29 UTC](https://github.com/heyvaldemar/catalog/blob/36f159428c25a943b5a8191f57da353e7d738353/fleet.json#L1201).
